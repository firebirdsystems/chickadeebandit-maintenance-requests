# Maintenance Requests

A [Chickadee Bandit](https://chickadeebandit.com/app-library/maintenance-requests) app.

Submit and track facility maintenance requests. Members report issues; leadership triages, assigns, and resolves them.

## Features

- Members submit issues.
- Leadership triages, assigns, and resolves.
- Status tracking per request.

## Install

In your hub, go to **Apps → Install from URL** and paste:

```
https://github.com/firebirdsystems/chickadeebandit-maintenance-requests/releases/latest/download/bundle.json
```
